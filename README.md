# Idle Games for Garmin

Idle games for Connect IQ watches. One directory per game.

| Game | Watches | What it is |
| --- | --- | --- |
| [`deep-shaft-tycoon/`](deep-shaft-tycoon/) | Venu 2, Venu 2 Plus, Venu 2S | An idle mining tycoon: eight shafts, managers that run them for you, offline earnings, and a prestige sell-off. |

Each game builds on its own:

```sh
cd deep-shaft-tycoon
tools/build.sh --fetch-sdk
```

See the game's own README for its mechanics, controls and tooling.
